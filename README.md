# Analytics Dashboard (React)

A general-purpose analytics web application built with React, Vite, and Tailwind CSS.

## Features
- CSV upload and parsing
- Global dataset state
- Search with debounce
- Multi-column filter chips
- Interactive charts (Recharts)
- Responsive sidebar layout

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Recharts
- PapaParse

## Getting Started
```bash
npm install
npm run dev
